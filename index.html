Standard procedure for incoming inspections, local yard fixes, and escalation to Keller Global Services (KGS).

SIMPLE RULE: Inspect ➔ Power On ➔ Test ➔ Repair if Failed ➔ Re-test ➔ Maintenance ➔ Final Test ➔ Record ➔ Release
1. Receive & Check Logbook / Shipment Form
2. Inspect for Physical Damage ➔ Report Supervisor if Found
3. Power On ➔ Execute Functional Test (Switch, Control Board, Fan, Terminals, Remote, Inverter, Filters)
4. If Failed: Can be fixed locally? ➔ NO ➔ Source to KGS for Repair/Replacement
5. If Passed: Maintenance ➔ Final Test (Depth, Ampere, Frequency, RIG Controller) ➔ Release
MANDATORY RULE

NO VERIFIED ISOLATION = NO WORK

  1. Identify & Prepare: Confirm equipment, energy sources, and notify affected personnel.
  2. Stop Equipment: Shut down using normal operational procedures.
  3. Isolate: Disconnect all power and isolation switches.
  4. Lock & Tag: Attach physical lock and "DO NOT OPERATE" tag.
  5. Release & Verify: Discharge stored energy and verify zero voltage state before touching.
  6. Perform Work: Proceed safely under verified conditions.
  7. Remove & Test: Reassemble guards, clear personnel, remove LOTO, and test equipment.
